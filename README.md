# Meals

A Flutter recipe app for browsing meals by category, viewing recipe details, and keeping a list of favorites.

## Features

- Browse meals in categories such as Italian, Quick & Easy, Breakfast, and Asian.
- View each meal's image, preparation time, difficulty, affordability, ingredients, and cooking steps.
- Add or remove meals from the Favorites tab.
- Filter the meal catalogue by gluten-free, lactose-free, vegetarian, and vegan options.
- Navigate between categories, favorites, and filter settings using the app navigation and drawer.

The app currently uses a built-in sample catalogue. Favorite selections and filter settings are held in app state and are not persisted between launches.
